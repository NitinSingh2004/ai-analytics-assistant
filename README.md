# AI Data Chat Dashboard

An AI-powered analytics dashboard built using Streamlit and PandasAI that allows users to upload datasets and interact with them using natural language.

The project combines:

- Streamlit for frontend UI
- PandasAI for AI-powered dataframe analysis
- LLM integration for intelligent responses
- Interactive charts and visualizations
- Chat-based data exploration

---

# Features

✅ Upload CSV or Excel files  
✅ Ask questions in natural language  
✅ Generate charts automatically  
✅ AI-powered dataframe analysis  
✅ Interactive Streamlit dashboard  
✅ Fast and lightweight  
✅ Easy to extend with Groq/OpenAI APIs
